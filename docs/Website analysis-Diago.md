# **1\.**  **Observation**

| Menu | Simple text menu. No dropdowns, no search bar. |
| :---- | :---- |
| **Homepage** | Feels short and simple —need to add more sections/images. |
| **Trust signals** | Mention of certified diamonds and hallmark gold, but there is no guarantee, review, or after-sale promise shown. |
| **Shopping** | All "Collections" links go to one generic page. No way to browse by price, occasion, or gender. |
| **Photos** | Currently very few photos. We should try to double the number of photos — add close-up shots, on-model shots, for each of your seven collections. More photos make the brand feel bigger and more established.   |
| **Tone of voice** | Clean and modern. Its good, we can keep same. |
| **Emotional appeal** | Is fine.  But No gifting page, no styling tips, no customer reviews.  |
| **Fonts** | Need to change. Use a stylish serif font for headings (like Playfair Display) and we can keep current clean font for body text. Right now everything uses one font style — mixing two fonts is the fastest way to look more premium. |
| **Colour** | Alternating light and dark sections gives the page good feel, like a real jewellery showroom.  |
| **Spacing** | Add more space between sections — about 30% more than today. Luxury websites do this..  |
| **Effects** | Add small animations: photos that zoom slightly on hover |
